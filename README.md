### Docker compose about DontStarveTogether

begin.sh 是启动脚本，直接启动 利用start.sh脚本启动

end.sh 是关闭脚本

.klei下是存档，复制自己的来，记得配置`cluster_token.txt`

`dedicated_server_mods_setup.lua`内容是服务器mod，需要填写服务器mod的id，之后需要自己复制到docker内的`/root/dontstarvetogether_dedicated_server/mods/dedicated_server_mods_setup.lua`

仅供学习参考，不一定是最优的
